# Multivariate Analysis on Environmental & Transportation Trends
> **Examining the Relationship between Greenhouse Gas (GHG) Emissions and Transport Infrastructure across 150+ Countries**

โปรเจกต์วิเคราะห์เชิงสถิติขั้นสูงเพื่อศึกษาความสัมพันธ์ระหว่างปัจจัยด้านโครงสร้างพื้นฐานคมนาคมกับการปล่อยก๊าซเรือนกระจกในระดับสากล โดยใช้เทคนิคการจัดกลุ่มและการจำแนกกลุ่มเพื่อระบุลักษณะร่วมของประเทศต่างๆ

## 📌 บทสรุปโครงการ (Project Overview)
* **วัตถุประสงค์ (Objective):** เพื่อสำรวจความสัมพันธ์ระหว่างปริมาณการปล่อยก๊าซเรือนกระจก (GHG) จากภาคขนส่ง และดัชนีโครงสร้างพื้นฐานทางการคมนาคม (GCI) ในระดับนานาชาติ
* **ปัญหา (Problem):** การพัฒนาโครงสร้างพื้นฐานมักส่งผลกระทบต่อสิ่งแวดล้อม การระบุกลุ่มประเทศที่มีลักษณะการปล่อยมลพิษคล้ายคลึงกันจะช่วยให้นักนโยบายออกแบบแนวทางแก้ปัญหาที่ตรงจุดได้
* **ข้อมูล (Data):** ชุดข้อมูลสถิติจากธนาคารโลก (World Bank) และรายงานดัชนีขีดความสามารถในการแข่งขัน (GCI) ครอบคลุมประเทศกลุ่มตัวอย่างทั่วโลก

## 🛠️ เทคนิคและเครื่องมือ (Tech Stack)
* **Language:** R (ใช้สำหรับการประมวลผลทางสถิติและสร้างภาพข้อมูล)
* **Statistical Methods:**
    * **Cluster Analysis (K-Means):** สำหรับการจัดกลุ่มประเทศที่มีลักษณะใกล้เคียงกันออกเป็น 4 กลุ่มหลัก
    * **Discriminant Analysis:** เพื่อสร้างแบบจำลองจำแนกประเภทและยืนยันความแม่นยำของการจัดกลุ่ม
    * **Descriptive Statistics:** วิเคราะห์ค่ากลางและความแปรปรวนของข้อมูลสิ่งแวดล้อม
* **Key Metrics:** วิเคราะห์ค่าการปล่อยก๊าซเรือนกระจก (CO2 equivalent) เปรียบเทียบกับคุณภาพโครงสร้างพื้นฐาน

## 📊 ขั้นตอนการดำเนินงาน (Methodology)
1. **Data Preprocessing:** รวบรวมและทำความสะอาดข้อมูลสิ่งแวดล้อมและเศรษฐกิจ ตรวจสอบค่าที่ขาดหายและปรับสเกลข้อมูล (Standardization)
2. **Cluster Analysis:** แบ่งกลุ่มประเทศออกเป็น 4 กลุ่มตามระดับการพัฒนาและผลกระทบต่อสิ่งแวดล้อม
3. **Discriminant Analysis:** ทดสอบประสิทธิภาพของตัวแปรในการจำแนกกลุ่ม พร้อมวิเคราะห์ฟังก์ชันจำแนกประเภท (Discriminant Functions)
4. **Validation:** ตรวจสอบความถูกต้องของการจำแนกประเภทด้วย Hit Rate และประเมินนัยสำคัญของแบบจำลอง

## 🚀 ผลการศึกษาและข้อเสนอแนะ (Results & Insights)
* **Key Discovery:** สามารถแบ่งกลุ่มประเทศได้อย่างชัดเจนตามระดับความยั่งยืน และระบุกลุ่มประเทศอุตสาหกรรมที่เป็น "ตัวแปรผิดปกติ" (Outliers) ซึ่งปล่อยก๊าซ GHG สูงกว่ากลุ่มอื่นอย่างมีนัยสำคัญ
* **Insight:** โครงสร้างพื้นฐานที่มีคุณภาพสูงมักมีความสัมพันธ์กับปริมาณการปล่อยก๊าซที่เพิ่มขึ้นในระยะแรก แต่ในประเทศกลุ่มที่เน้นความยั่งยืนจะเริ่มเห็นแนวโน้มการควบคุมมลพิษที่มีประสิทธิภาพมากขึ้น
* **Policy Implication:** ผลลัพธ์นี้ช่วยในการออกแบบนโยบายลดก๊าซเรือนกระจกรายกลุ่มประเทศ (Differentiated Policies) ตามระดับขีดความสามารถในการแข่งขันของแต่ละประเทศ
